# TATLEARN — Tattoo Learning Studio

Mobile-first Thai tattoo education web app built with Vite and React. Dark red minimal glass design.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Features

- Curriculum: 37 original Thai tattoo-technique lessons with goals, practice drills, caution and self-check
- Responsive dashboard with actual persisted progress (no fabricated stats)
- Pointer-enabled digital drawing practice canvas with guides, undo/redo and PNG export
- Interactive 8-layer metallic gold/silver illustration simulator
- Vector-rendered Anubis masterclass with 9 progressive layers, show-guide and SVG export
- 30-day training map, checkable equipment, safety resources, quiz with 20 questions
- Left-arm sleeve planner, training journal and JSON import/export
- Offline-first app data in browser localStorage (no accounts or back-end)

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Framework: Vite

## Safety

All drills target paper, digital drawing and synthetic skin. Do not tattoo a human based only on this app. Professional supervised training, infection-control standards and local regulations are required before real-skin work. Practice inks and artist metallic paints are not safe substitutions for licensed professional tattoo pigments.

Source reference links are in the Setup & Safety section.
