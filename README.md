# TATLEARN — ฝึกสักทีละขั้น

เว็บเรียนและฝึกสักแบบ Mobile-first ด้วยโครงเดียว **ดูตัวอย่าง → ทำตาม → จับเวลา → ตรวจผลงาน** ใช้ภาพศึกษาและหนังเทียมเป็นหลัก ไม่ใช่คำแนะนำให้สักคนจริง

## 3 ช่วงฝึก
1. พื้นฐาน 8 แบบฝึก — อุปกรณ์ ลอกลาย เส้นตรง เส้นโค้ง วงกลม หัวเข็ม เงา และเรขาคณิต
2. สีและโลหะ 8 แบบฝึก — แดง น้ำเงิน เขียว ม่วง การไล่สี ทอง เงิน และโรสโกลด์
3. ภาพเต็ม 4 แบบฝึก — Mandala, Anubis ศีรษะ, อัญมณีสี, Anubis เต็มภาพ

ทุกแบบมีภาพต้นแบบ ขั้นตอนสั้น แบบพิมพ์ A4 (เมื่อมี) นาฬิกาจับเวลาและนับถอยหลัง การตรวจ 3 ข้อ ถ่ายภาพเพื่อเทียบแบบเฉพาะในเบราว์เซอร์ และบันทึกเวลาที่ใช้จริง เมื่อตรวจผ่านทั้งสามข้อจึงนับว่าผ่าน (เป็นการประเมินด้วยตนเองเท่านั้น)

## UX
- Header มีโลโก้ + hamburger
- หน้าหลักมีเพียง 3 ช่วงฝึกและรายการฝึก เน้นแตะแล้วเริ่ม
- คลังความรู้ ภาพสอน แผ่นฝึก หัวเข็ม กระดานดิจิทัล แบบทดสอบ อุปกรณ์ แผน 30 วัน ประวัติ และงานแขนซ้าย อยู่หลัง hamburger
- โทนดำแดง กระจกโปร่งบางเฉพาะ header/drawer; ไม่มี carousel หรือส่วนโปรโมตจำนวนมาก
- เก็บการฝึกและเวลาไว้ใน localStorage เช่นเดิม รวมถึงนำเข้า/ส่งออกข้อมูล JSON

## Run

```bash
npm install
npm run check
npm run build
npm run dev
```

Cloudflare Workers/Pages static output: `dist`, command: `npm run build`.

## ไฟล์ภาพ
- ภาพเวกเตอร์ใน `public/visual-lessons/`
- แบบฝึก A4 SVG ใน `public/worksheets/`
- การทดลองภาพชิ้นงานผ่าน input file เป็น preview ชั่วคราวเท่านั้น **ไม่อัปโหลดและไม่บันทึกไฟล์ภาพ** (บันทึกได้เฉพาะเวลา/ผลเช็กลิสต์/โน้ต)

## ความปลอดภัย
กิจกรรมในเว็บสำหรับกระดาษและหนังเทียม เครื่องและหัวเข็มต้องใช้งานตามคู่มือของรุ่น ไม่แนะนำค่าความลึกหรือแรงดันสากล การสักบนคนต้องฝึกกับช่างที่มีประสบการณ์และทำตามมาตรฐานควบคุมการติดเชื้อและกฎหมายที่เกี่ยวข้อง
